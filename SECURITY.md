| Version | Supported          |

---

## Reporting a Vulnerability

We take the security of **Spelling Master** seriously. If you discover a security vulnerability, please follow these guidelines:

1. **Do NOT disclose the issue publicly** in GitHub Issues or public forums.
2. Please report the vulnerability privately to the project maintainers via email or through GitHub's [Private Vulnerability Reporting](https://github.com/rr0845-design/Spelling-Treasure/security/advisories/new).
3. Include detailed information:
   * Description of the vulnerability
   * Steps to reproduce or proof of concept
   * Potential impact
4. We will acknowledge receipt of your report within 48 hours and work on a prompt resolution.

Thank you for helping keep our learning platform secure!

# Contributing to Spelling Master

Thank you for your interest in contributing to **Spelling Master**! 🎉

We welcome contributions of all kinds: bug fixes, feature proposals, educational enhancements, UI/UX polish, and documentation improvements.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
* Check the [Issues tab](https://github.com/rr0845-design/Spelling-Treasure/issues) to see if the issue has already been reported.
* If not, create a new issue using the **Bug Report** template.
* Include detailed steps to reproduce the issue, device/browser info, and screenshots if possible.

### 2. Suggesting Features
* Open an issue using the **Feature Request** template.
* Describe the educational value or enhancement clearly.

### 3. Pull Requests (Code Contributions)
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/my-cool-feature` or `git checkout -b fix/bug-fix-name`.
3. Make your changes adhering to existing code conventions (Vanilla JavaScript, clean CSS, semantic HTML).
4. Test thoroughly across desktop and mobile screens.
5. Commit your changes: `git commit -m "Add new feature or fix bug"`.
6. Push to your branch: `git push origin feature/my-cool-feature`.
7. Open a **Pull Request** explaining your changes.

---

## 🎨 Code Style Guidelines

* **JavaScript:** Modern ES6+, semantic function names, non-blocking asynchronous calls (`fetch`, `Promise`).
* **CSS:** TailwindCSS utility classes combined with custom Patina Glassmorphism styles in `style.css`.
* **Apps Script (`Code.gs`):** Batch Google Sheets operations (`setValues`) and safe data validation (`isRealVocabWord`).
